# Hybrid Icarus Dedicated Server

This project deploys a secure Icarus dedicated server using a Hybrid Cloud Architecture.

- **Game Server**: Runs locally, dockerized on your hardware, utilizing your CPU and RAM.
- **Gateway**: Runs on a cheap AWS Lightsail instance (provisioned with Terraform).
- **Tunnel**: UDP Traffic is securely tunneled via FRP from the Cloud to your local server.
- **Web Dashboard**: Serves a secure HTTPS server status page to easily check if the game is online.

## Prerequisites
- Terraform installed
- Docker & Docker Compose installed locally
- DuckDNS Account & Token
- AWS Account with Lightsail permissions, and the AWS CLI configured with credentials (`aws configure`, or `aws configure --profile <name>` and set `aws_profile` in `terraform.tfvars`)

**Cost:** the gateway is a Lightsail `nano` instance, roughly US$5/month with a public IPv4 address (check current [Lightsail pricing](https://aws.amazon.com/lightsail/pricing/)). The static IP is free while attached.

## Quick Setup
1. Copy `cloud/terraform.tfvars.template` to `cloud/terraform.tfvars` and fill it in. The gateway defaults to `eu-west-2` (London); set `aws_region` and `availability_zone` to use a region closer to your players.
2. Run `make cloud-deploy` to provision the AWS infrastructure (review the plan and type `yes`).
3. Copy `local/.env.template` to `local/.env` and configure your Icarus server name/passwords. `RESTIC_PASSWORD` is required. (The tunnel config, `local/frpc.toml`, is generated by step 2.)
4. Run `make local-up` to start the Icarus game server, the FRP tunnel client, and the automated backup container.

Run `make` (or `make help`) to list all available commands.

> **Keep `cloud/terraform.tfstate` private.** Terraform state stores your tokens, dashboard password and the gateway's SSH private key in plain text. It is git-ignored; never commit or share it.

## Connecting

Visit `https://yourdomain.duckdns.org` in a browser to view the server status and connection instructions.

Players add `yourdomain.duckdns.org:27015` to their Steam server favourites (**View > Game Servers > Favorites**), then join from **Play > Dedicated Servers** in Icarus.
- `27015/udp` is the Steam **query port**, used by the server browser to find the server.
- `17777/udp` is the **game port**, carrying the gameplay traffic once connected.

The local game container also publishes both ports on your host so players on your LAN can connect directly. They aren't reachable from the internet unless you forward them on your router, which this setup doesn't need. Remove the `ports:` section in `local/docker-compose.yml` if you don't want LAN access.

## Backups

The `backup` container takes an encrypted [restic](https://restic.net/) snapshot of `local/data` every 4 hours, keeping 7 daily and 4 weekly snapshots, in `local/backups/`.

Backups are stored on the same disk as the server. For protection against disk failure, change the `./backups` volume in `local/docker-compose.yml` to a path on another drive (or sync `local/backups/` elsewhere). Keep your `RESTIC_PASSWORD`: backups can't be restored without it.

To restore the latest snapshot:
```bash
make local-down
cd local
docker compose run --rm -v "$PWD/restore:/restore" backup sh -c "apk add --no-cache restic && restic restore latest --target /restore"
mv data data.old
sudo mv restore/data data && sudo rmdir restore
cd .. && make local-up
```
To restore an older snapshot, list them by replacing the `restic restore ...` part with `restic snapshots`, then use the snapshot ID instead of `latest`.

## Migrating a Local World to the Server

If you have been playing locally with friends and want to move your progress to this dedicated server, follow these steps:

1. **Start the server once** by running `make local-up` to ensure the folder structure is generated, then stop it via `make local-down`.
2. On your gaming PC, press **Win + R**, paste `%LocalAppData%\Icarus\Saved\PlayerData`, and hit Enter.
3. Open the folder named after your SteamID64, then open the `Prospects` folder. Locate the `.json` file of the world you want to transfer.
4. Copy this `.json` file to the equivalent folder on your server machine: 
   `local/data/Saved/PlayerData/DedicatedServer/Prospects/` (create the folders if they don't exist).
5. Start the server again using `make local-up`.
6. Load the prospect into the running server using the following command (replace with your save name):
   ```bash
   make load-prospect PROSPECT=YourSaveFileName
   ```
   *(Note: The server image wipes `LoadProspect` on boot, so you must use this command to inject it while running. Since `ResumeProspect=True` is set by default, the server will remember it for future restarts!)*

*Note: Character progression (level, talents, unlocks) is stored locally on each player's PC. This means your progression stays with you seamlessly when moving between local play and the dedicated server!*
